# Мультиязычность MyTamga — план реализации

> **Для агентов-исполнителей:** ОБЯЗАТЕЛЬНЫЙ СУБ-СКИЛЛ: superpowers:subagent-driven-development
> (рекомендуется) или superpowers:executing-plans. Шаги размечены чекбоксами.

**Цель:** сайт на русском, узбекском (латиница), английском и китайском
(упрощённом) с переключателем языка в стиле переключателя темы.

**Архитектура:** корневой layout переезжает в `app/[lang]`, четыре версии
пререндерятся статически. `proxy.ts` уводит голый `/` на язык из cookie,
`Accept-Language` или на русский. Словари — TypeScript, типизированные по
русскому, так что неполный перевод не соберётся. Серверные секции берут язык
из `next/root-params`, клиентские компоненты получают строки пропсами.

**Стек:** Next.js 16.3 (`proxy`, `next/root-params`, `LayoutProps`/`PageProps`),
React 19, Tailwind v4, framer-motion.

**Спека:** `docs/superpowers/specs/2026-09-14-i18n-design.md`

## Глобальные ограничения

- Новых зависимостей нет. `server-only` берётся из Next (`dist/compiled`).
- Языки и `<html lang>`: `ru`→`ru`, `uz`→`uz-Latn`, `en`→`en`, `zh`→`zh-Hans`.
- В `/uz`, `/en`, `/zh` в видимом тексте — ни одного кириллического символа.
- Подписи `LiquidMetalButton` — не длиннее 21 символа на любом языке:
  ширина кнопки считается как `символы × 8.4 + 48` с потолком 232px.
- Узбекский и китайский словари помечены `REVIEW(translation)`.
- В `globals.css` — только цвет и форма; `display` и раскладка — утилитами.
- Тёмная тема на `/ru` вне хедера совпадает со слепком.
- Механизм — по `node_modules/next/dist/docs/01-app/02-guides/internationalization.md`,
  `…/03-file-conventions/proxy.md`, `…/04-functions/next-root-params.md`.

import { en } from "./dictionaries/en";
import { ru, type Dictionary } from "./dictionaries/ru";
import { uz } from "./dictionaries/uz";
import { zh } from "./dictionaries/zh";

const DICTIONARIES: Record<Locale, Dictionary> = { ru, uz, en, zh };

export function getDictionary(locale: Locale): Dictionary {
  return DICTIONARIES[locale];

  return { locale, t: getDictionary(locale) };

```ts
import { NextResponse, type NextRequest } from "next/server";

import { DEFAULT_LOCALE, LOCALE_COOKIE, hasLocale, type Locale } from "@/lib/i18n/config";

// Four locales don't need a negotiation library: rank by q, match on the
// primary subtag (zh-TW → zh, uz-Cyrl → uz).
function fromAcceptLanguage(header: string | null): Locale | null {
  if (!header) return null;
  const ranked = header
    .split(",")
    .map((part) => {
      const [tag, ...params] = part.trim().split(";");
      const q = params.map((p) => p.trim()).find((p) => p.startsWith("q="));
      return { primary: tag.trim().toLowerCase().split("-")[0], q: q ? Number(q.slice(2)) || 0 : 1 };
    })
    .filter((entry) => entry.primary && entry.q > 0)
    .sort((a, b) => b.q - a.q);
  return ranked.find((entry) => hasLocale(entry.primary))?.primary as Locale | undefined ?? null;
}

export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;
  if (hasLocale(pathname.split("/")[1] ?? "")) {
    return NextResponse.next();
  }
  const cookie = request.cookies.get(LOCALE_COOKIE)?.value;
  const locale =
    (cookie && hasLocale(cookie) ? cookie : null) ??
    fromAcceptLanguage(request.headers.get("accept-language")) ??
    DEFAULT_LOCALE;
  const url = request.nextUrl.clone();
  url.pathname = `/${locale}${pathname === "/" ? "" : pathname}`;
  return NextResponse.redirect(url);
}

// Constant, as the matcher must be statically analysable. Excludes Next's own
// assets and anything with a file extension, or the locale redirect would
// swallow CSS and JS.
export const config = {
  matcher: ["/((?!_next|api|.*\\..*).*)"],
};
```

- [ ] **Шаг 1: CSS.** Материал дорожки и бегунка у `.cts` выносится в общие
  селекторы: `.cts, .lss` — дорожка, `.cts-thumb, .lss-thumb` — бегунок

- [ ] **Шаг 2: Компонент.** `<nav data-lang-switcher aria-label={label}>` с
